# Tutorials

These tutorials show how to use Model Live Diagnostics in an ARE JupyterLab session. If you are new to the package, start with Getting started.

- [Getting started](getting_started_tutorial.md): start a session on an existing model run, plot its data, compare it with reference models, run analysis recipes and end the session.
- [Built-in analysis recipes](built_in_recipes_tutorial.md): what each built-in recipe computes, the data it expects and its options.
- [Adding custom analyses](adding_custom_analyses.md): write your own analysis recipes, with their own options, plot customisations and suites of plots, and add them to the interface.
- [Advanced usage](advanced_usage.md): what happens when a session starts, working with the catalogue and loaded dataset in Python, session management and troubleshooting.
