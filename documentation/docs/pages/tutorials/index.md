# Tutorials

These tutorials show how to use Model Live Diagnostics in an ARE JupyterLab session. If you are new to the package, start with Getting started.

- [Getting started](../../notebooks/getting_started_tutorial.md): learn the plotting controls on existing reference models, then start a session on your own run, compare it with reference models, run analysis recipes and end the session.
- [Advanced usage](../../notebooks/advanced_usage.md): what happens when a session starts, working with the catalogue and loaded dataset in Python, session management and troubleshooting.
- [Adding custom analyses](../../notebooks/adding_custom_analyses.md): write your own analysis recipes, with their own options, plot customisations and suites of plots, and add them to the interface.
- [Built-in analysis recipes](../../notebooks/built_in_recipes_tutorial.md): what each built-in recipe computes, the data it expects and its options.
