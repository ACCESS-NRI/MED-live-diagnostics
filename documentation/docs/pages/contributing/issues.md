# Feature requests and bug reports

We welcome bug reports, feature requests, and other suggestions. Please submit them through the [GitHub issue tracker](https://github.com/ACCESS-NRI/MED-live-diagnostics/issues/new/choose).

When suggesting a feature, explain how it should work and keep the scope as narrow as possible. This makes features easier to implement.

When reporting a bug, include:

- Details about your local setup, especially the Python interpreter version.
- Detailed steps to reproduce the issue, ideally with a [Minimal, Complete and Verifiable Example](https://matthewrocklin.com/minimal-bug-reports).
- A demonstration test that currently fails but should pass when the issue is fixed, when possible.
